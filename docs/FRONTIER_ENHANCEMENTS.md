# Frontier enhancement roadmap

Last reviewed: 2026-08-13

This roadmap translates recent primary research into bounded SYNAPSE-S2 work. It does not treat paper benchmarks as guarantees for this implementation. Every retrieval, compression, or representation change must earn promotion through local accuracy, latency, resource, privacy, and deletion-fidelity tests.

## Ranked opportunities

1. **Local multimodal image memory.** Transient source handling, a low-resolution thumbnail, an explicit searchable description, and bounded deterministic pixel descriptors now have an opt-in Apple Vision lane. Apple [image feature prints](https://developer.apple.com/documentation/vision/vngenerateimagefeatureprintrequest) provide image-to-image similarity features, while [text recognition](https://developer.apple.com/documentation/vision/vnrecognizetextrequest) provides imperfect OCR cues. Neither is a VLM or text-to-image semantic search. [SigLIP 2](https://arxiv.org/abs/2502.14786) and Apple [FastVLM](https://github.com/apple/ml-fastvlm) remain later options, not baseline dependencies.
2. **Proof and impact telemetry.** Adapt a small deterministic fixture set from the evaluation dimensions in [LongMemEval](https://arxiv.org/abs/2410.10813) and multimodal [LongMemEval-V2](https://arxiv.org/abs/2605.12493): factual recall, updates, temporal reasoning, workflows, environment gotchas, premise awareness, abstention, image evidence, bridge isolation, and deletion. Report accuracy or recall, bounded-context bytes/tokens, p50/p95 latency, cache hits, deduplication, and deletion residue. Dollar output is only an equivalent estimate based on a user-configured input-token rate; it is not a bill or proven counterfactual saving.
3. **Compact abstractions and cue anchors.** Borrow the separation in [Memora](https://arxiv.org/abs/2602.03315): preserve a source-backed memory value while indexing a compact primary abstraction and multiple cue anchors. Explicitly consented, redacted Apple Vision OCR already participates as a searchable cue; future learned cross-modal features and visual identifiers may add further cues linked to the typed image-memory record. Generated cues must remain versioned, attributable, reviewable, and regenerable.
4. **Type-aware evidence retrieval.** Make neuron types affect retrieval budgets, not only presentation. Route and fuse bounded evidence from facts/text, temporal transitions, procedures/gotchas, files, and images. LongMemEval-V2's structured pools are evidence that typed observations, events, and strategy notes are worth testing; they do not prove that its reported gains transfer to SYNAPSE-S2.
5. **Bi-temporal validity and supersession.** Evaluate `valid_from`, `valid_to`, `recorded_at`, `supersedes`, and source-event provenance, following the temporal context-graph direction in [Zep/Graphiti](https://arxiv.org/abs/2501.13956). Current-fact recall and historical recall must be explicit modes, with deterministic late-arrival and contradiction tests.
6. **Bounded graph activation.** Test a HippoRAG 2-inspired Personalized PageRank reranker seeded by existing spike, semantic, and surface matches. [HippoRAG 2](https://arxiv.org/abs/2502.14802) reports stronger associative retrieval in its own setting. SYNAPSE-S2 must cap hops, honor approved bridge scope, preserve direct-retrieval fallback, and prove that graph propagation does not leak or over-amplify weak links.
7. **Salience-guided memory hygiene.** Explore novelty, correction value, task impact, verification, and observed reuse as review signals, informed by surprise-driven memory in [Titans](https://arxiv.org/abs/2501.00663) and evolving structured notes in [A-MEM](https://arxiv.org/abs/2502.12110). These signals may prioritize or propose archival; they must not silently delete durable memory.
8. **Compact embeddings and prompt packing.** The deployed Qwen3 embedding family supports custom Matryoshka dimensions ([official repository](https://github.com/QwenLM/Qwen3-Embedding)). A smaller shortlist plus full-vector rerank may be worth benchmarking. [RaBitQ](https://arxiv.org/abs/2405.12497) is a later high-scale ANN option, while [LLMLingua-2](https://arxiv.org/abs/2403.12968) is an optional post-retrieval compressor. Embedding changes require governed reindexing; prompt compression must be tested for lost negation, qualifiers, provenance, and instructions.

## Implementation boundary

### Shipped foundation

- Local image capture leaves the operator's source untouched and does not copy or retain it. The dashboard downsamples in browser memory; the CLI validates and holds the source while deriving an owner-only JPEG thumbnail beneath the verified binding data root. Both commit an explicit searchable description plus a bounded `16 x 16 x 3` byte tensor, RGB histogram, edge histogram, and difference bits as typed `image` memory metadata. Optional Apple Vision enrichment runs in a short-lived process on a maximum-2048-pixel derivative: feature-print bytes remain only in the owner-only node-local media object, while durable metadata stores provider/revision/type/count/reference; explicitly consented OCR is redacted before it is stored and indexed as a cue. A missing helper degrades to a visible receipt unless enrichment was marked required. Feature prints are image-to-image similarity features only, and OCR can be wrong or sensitive.
- Governed image-to-image feature-print recall now exists as the CLI `image-similar` command and the read-only `query_spiking_media_similarity` MCP tool (compact `media-similarity` token-contract surface). Both gate the query and every candidate on the authoritative scope-filtered media-reference listing (`list_media_references`, local/connected/all), require exact provider/schema/request-revision/element-type/count/input-derivative compatibility, compute a deterministic bounded streaming top-k with the versioned `s2-feature-vector-l2-v1` metric and `distance`-then-`media_id` tie-break, enforce strict result/candidate/byte/time limits, and return only content-free media IDs, uncalibrated scores, public descriptors, and thumbnail availability — never feature bytes, OCR text, or descriptor tensors. A reference the durable store still holds but the private cache cannot serve fails closed as integrity drift. Cross-device semantic compatibility is never invented: incompatible feature-print revisions or providers are excluded and counted.
- Stored-image similarity is fully wired into the authenticated local dashboard: the Image Memory gallery exposes an accessible per-thumbnail "Find similar" action backed by the read-only `GET /api/media-similar` route. The browser names only the query media ID, context, scope, and limits; the server resolves candidates from the authoritative reference listing (client-supplied candidate IDs are never trusted), reuses the exact `query_similar_media` contract, and maps not-referenced/incompatible/drift failures to content-free 404/409 responses. The panel renders ranked thumbnail cards with distances, an explicit uncalibrated warning, truncation/exclusion notices, Escape-key dismissal, and a 390-px single-column layout — never feature bytes or OCR text.
- A transient query lane (`media_similarity.query_similar_media_transient`, surfaced as the CLI `image-similar-transient` command) ranks the same authoritative candidates against a private, owner-only (0600) regular query file without creating any durable artifact: the feature print comes from the same short-lived Apple Vision helper, is privatized and decoded in memory, and the projection records only transient provenance plus a content-free compatibility descriptor. No query object, manifest, vector, OCR, or digest is persisted; helper unavailability or timeout is a content-free error; the media-cache inventory is bit-identical before and after success or failure. The remaining same-UID pathname TOCTOU between validation and the helper's own re-check is an explicitly documented trust boundary of this node-local lane. No transient MCP upload/path tool is exposed.
- Media derivatives now participate in verified paired backup/restore and offline replication. Recovery bundle v3 (`synapse-s2.recovery-bundle.v3`) seals a digest-bound media archive built from the immutable database snapshot's own reference set: a referenced-but-missing or corrupt derivative blocks publication, valid orphans are excluded and reported, and restore materializes derivatives only inside the isolated proof root with per-member digest re-verification and full object re-validation. Replication carries the archive as the digest-bound `media` artifact kind through staging and acknowledgement. Media-absent v2/v1 bundles remain verifiable and restorable but report `media_recovery_complete: false` whenever image references exist. Full-resolution originals are never copied anywhere in this lifecycle.
- The hidden far-right footer Impact drawer records one content-free, all-namespace aggregate of dashboard recall counters, non-empty yield, bridge/graph evidence assists, bounded recent backend-retrieval p50/p95 latency, response-byte token estimates, trace-cache occupancy, delivery acknowledgements, and topology headroom. It does not yet cover MCP, CLI, or agent hydration. Its editable dollar figure is a `$0`-to-upper-bound what-if range; it is not billing or proven savings.
- Image-cache integrity has a content-free audit, owner-only layout checks, atomic publication, deterministic retry binding, authoritative media-reference enumeration, verified recovery/replication inclusion, and revision-guarded orphan pruning at the module boundary. Atomic whole-memory-plus-derivative deletion and a governed operator prune surface remain prerequisites before promising complete derivative deletion.
- The local [memory confidence gate](MEMORY_CONFIDENCE_GATE.md) now exercises a fixed disposable fixture across static state, dynamic tracking, workflow knowledge, environment gotchas, premise awareness, factual recall, updates/supersession, temporal order, evidence-level abstention, bridge isolation, image-description recall, and logical/node-local derivative deletion. It emits a machine-readable fail-closed report with informational p50/p95 latency and never opens the live database, uses an LLM, or uses the network. This is a regression gate inspired by LongMemEval dimensions, not an official LongMemEval or LongMemEval-V2 score.
- New source-event captures now carry by default a bounded `synapse-s2.harmonic-scaffold.v1` navigation layer: one context-scoped primary abstraction and up to eight context-scoped cue anchors, preferably supplied through reviewed metadata and otherwise derived deterministically from structured, already-redacted source fields. The labels and stable IDs reuse `semantic_facets` and `memory_surface_terms`, so alternate vocabulary participates in existing hybrid retrieval while row deletion cascades every derivative index term. See [Harmonic memory scaffolding](HARMONIC_MEMORY.md). This is a source-backed, non-learned Memora-inspired baseline, not Memora's content consolidation or policy-guided retriever.
- [Memora Shadow and governed cue bindings](MEMORA_SHADOW.md) retain the bounded, deterministic planner over one exact namespace snapshot: at most 64 entries / 65,536 embedded bytes / 16 clusters / 8 cues per cluster, embedding only already-redacted durable text plus a whitelisted field set through the pinned local provider. A plan itself remains `mode: shadow`, `applied: false`, and `retrieval_effect: false`. Separately, a reviewed learned proposal can enter a durable propose/promote/reject/revoke/supersede lifecycle with two-actor confirmation and exact revision CAS. Only an integrity-valid promoted binding affects bounded Retrieval v2 cue routing; provider or source drift removes that effect. Recovery bundle v3, isolated restore, replication staging, operator readiness, cutover attestation v3, and replacement admission v5 cross-bind a content-free all-binding audit. `learned: true` still means pretrained inference only — never fine-tuning, LLM content merging, GRPO, or automatic promotion — and source rows stay immutable and independently deletable.

### Next, after the baseline passes

- Governed feature-print lookup, the authoritative media-reference index, and complete backup/restore/replication treatment shipped above. Still open: atomic memory-and-derivative prune (deletion currently remains the revision-bound cache-orphan cleanup plus whole-memory deletion; no SQLite-plus-filesystem atomicity is claimed). Learned image features stay outside the deployed text embedding space.
- Expand the shipped confidence gate with an authoritative media-reference index, recovery/replication residue probes, and periodic live-corpus sampling. The [Forgetting Residue Score study](https://arxiv.org/abs/2606.10062) is a useful warning that raw-only deletion can leave derived memory recoverable, not independent proof about SYNAPSE-S2.
- Benchmark bounded shared-cue expansion beyond direct query matching; keep the shipped source-backed primary abstractions and cue anchors at zero expansion hops until relevance, isolation, and deletion tests justify promotion.
- Add deterministic type-aware retrieval budgets and fusion, then compare them with the current retrieval path.
- Add bi-temporal validity and supersession only with late-arrival, conflict, historical-query, migration, backup, and restore coverage.

### Defer until benchmarked

- Personalized PageRank or other graph propagation across memory and approved bridges.
- Persistent VLM loading, automatic captioning, or SigLIP-style cross-modal indexing. Any optional visual model must be on-demand, resource-gated, unloadable, and locally measured before promotion.
- Embedding-space migration, Matryoshka shortlists, binary/vector quantization, or broad prompt compression.
- Automatic salience deletion or self-modifying memory summaries.

Raw image bytes are not themselves a semantic representation: a decoder and feature extractor must convert them into numeric features, OCR, or descriptors. Ordinary text recall uses the operator description plus any explicitly consented, redacted OCR cue. Deterministic pixel descriptors and Apple feature prints remain outside the deployed text embedding space; feature prints affect only the explicit, governed image-to-image recall surfaces above and never hybrid text retrieval.
